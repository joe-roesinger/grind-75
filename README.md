# Hello!

This work was all done my yours truly in a effort to review core fundamentals while starting my first job hunt in nearly a decade. No AI was utilized in these answers below (that would defeat the prupose of this entire exercise...)

## Tech Used

- [Python](https://www.python.org/): All code (for now...) will be written in python in an effort to become more fluent

- [LeetCode](https://leetcode.com/problems/): The solutions seen in this project will be soltuion to valious leetcode problems

- [Grind75](https://www.techinterviewhandbook.org/grind75/): Tool that generated a schedule of leetcode problems

## File Layout

Ill be trying to treat this process as a daily journal almost but with interview questions. The top portion of the solution will link the problem, followed by an outline of my brain vomit about possible solutions. Some of the statements might be wildly incorrect at first but hopefully the ends justify the means.

If I were to speak it out loud while whiteboarding out a problem, Im going to put it into text.
